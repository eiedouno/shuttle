# :lucide-file-pen-line: Contributing

## NO AI / LLMs Policy

This project strictly forbids the usage of blind use of LLMs, agents, or any other AI tools for any kind of contribution.

No issues or bug reports. No patches or PRs.

## Do not PR to main!

Due to how shuttle is constructed, it will always build from the upstream git release. To not have wide-spread errors and half-working concepts, only PR to the `dev` branch please.

**No PRs requested to main will be accepted.**
